#### Formas de comunicar lenguajes de programación
- APIs
	- Necesitas servidor dedicado
	- Estás limitado a que en general se usa JSON por TCP
- Colas
	- No se puede compartir el espacio de memoria
- CPYTHON para compartir cosas de C a Python
- Sockets => IP:PORT -> Protocolo Custom UDP, TCP, RAW
- Mapeo de memoria: LMAX Disruptor [Memory Mapping](https://www.geeksforgeeks.org/operating-systems/memory-mapping/)
